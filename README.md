# 📋 Task Manager - مدير المهام

برنامج سطح مكتب متكامل لإدارة المهام، مبني بلغة **Python** باستخدام مكتبة **Tkinter** وقاعدة بيانات **SQLite**، يدعم اللغتين العربية والإنجليزية مع ثيمين فاتح وداكن.

---

## ✨ المميزات

- 🔐 **نظام حسابات كامل**: تسجيل دخول + إنشاء حساب مع تشفير كلمات المرور (SHA-256).
- 📝 **إدارة المهام**: إضافة، تعديل، حذف، وإتمام المهام.
- 🎯 **أولويات المهام**: عالية / متوسطة / منخفضة مع تمييز لوني.
- 📅 **تاريخ استحقاق** لكل مهمة.
- 🔍 **تصفية المهام**: الكل / قيد التنفيذ / مكتملة.
- 🌗 **ثيمان**: فاتح (Light) وداكن (Dark) بألوان مريحة للعين.
- 🌍 **دعم اللغتين**: العربية (RTL) والإنجليزية (LTR).
- 📊 **تقرير بياني**: إحصائيات المهام + رسم أشرطة لتوزيع الأولويات + نسبة الإنجاز.
- 💾 **حفظ تلقائي**: تفضيلات المستخدم (اللغة والثيم) تُحفظ في قاعدة البيانات.
- 👤 **عزل البيانات**: كل مستخدم يرى مهامه فقط.
